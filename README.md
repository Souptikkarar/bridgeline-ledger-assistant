# Bridgeline Ledger Assistant

A command-line tool that answers plain-English questions about Bridgeline
Fabricators' FY2024-25 vendor ledger — running entirely on your own
machine, using a local Ollama model. No data leaves your computer, and no
paid or cloud AI service is used anywhere.

## How it works, in one sentence

Python does all the arithmetic (totals, dates, GST, overdue checks); the
local language model only turns your English question into a request
Python can run, and turns Python's answer back into a sentence — it never
calculates anything itself.

## Requirements

- Python 3.10+ with `pandas` installed
- [Ollama](https://ollama.com/download) installed, with at least one model
  pulled (see below) — **or**, if your machine can't run a local model at
  all, the tool still works in a reduced mode (see "No-LLM mode" below)

## Setup and run (5 commands)

```bash
pip install pandas
ollama pull qwen2.5:3b
cd src
python clean.py
python main.py
```

That's it — `main.py` opens an interactive prompt. Type a question like:

```
> How much do we owe Bharat Steel Works?
```

Type `quit` to exit.

## No-LLM mode

If Ollama isn't running or reachable, `main.py` detects this automatically
and switches to a reduced mode: a simple keyword matcher picks the right
answer function instead of the language model, and the raw structured
result is printed instead of an English sentence. All the numbers are
still exactly correct — you just lose the natural-language phrasing. This
means the tool is still useful even on a machine that can't run any local
model at all.

## Example questions it can answer

- "How much do we owe Bharat Steel Works?"
- "Which invoices are overdue as at 31 March 2025?"
- "Which vendor did we spend the most with?"
- "List invoices with a taxable amount above Rs. 5,00,000"
- "What was the total GST charged in Q3?"
- "Which invoices can't be claimed for input tax credit?"
- "What's the average payment delay for Fabrication?"
- "Are there any duplicate or suspicious entries?"

See `EVALUATION.md` for the full list of 12 questions this was tested
against, with hand-calculated answers and PASS/FAIL results.

## A note on trust

Every number this tool produces traces back to specific invoice rows in
`ledger_clean.csv` — the tool always shows its source, not just an answer.
`DECISIONS.md` documents every judgement call made while cleaning the
ledger (vendor name matching, duplicate resolution, currency conversion,
what counts as "overdue"), since the underlying policy document leaves
some of these genuinely ambiguous.
